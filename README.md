# 🍔 Cardápio Online com Integração ao WhatsApp

Este projeto é um cardápio digital desenvolvido para facilitar pedidos em estabelecimentos como hamburguerias. Ele permite que os clientes:

- Visualizem os itens disponíveis no cardápio
- Adicionem produtos ao carrinho
- Finalizem o pedido enviando as informações diretamente para o WhatsApp do estabelecimento

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação da página
- **Tailwind CSS**: Estilização rápida e responsiva
- **JavaScript**: Lógica de interação e manipulação do carrinho
- **WhatsApp API**: Envio do pedido via link direto

---

## 🖼️ Funcionalidades

- 📋 Exibição dos produtos com nome, descrição e preço
- 🛒 Adição e remoção de itens no carrinho
- 💰 Cálculo automático do total do pedido
- 📲 Envio do pedido para o WhatsApp do estabelecimento com todos os detalhes

---

## 📚 Objetivo do Projeto

Este projeto foi desenvolvido com fins educacionais, visando praticar:

- Manipulação do DOM com JavaScript.

- Estilização responsiva com Tailwind CSS.

- Integração de aplicações web com APIs externas (WhatsApp).
  
---

## 📁 Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/JulianoLand/cardapio.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
    cd cardapio
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o projeto:
   ```bash
   npm start
   ```

## 📲 Integração com WhatsApp

Ao finalizar o pedido, o cliente será redirecionado para o WhatsApp com uma mensagem pré-formatada contendo os itens selecionados e o valor total. Isso facilita a comunicação e agiliza o processo de atendimento.
